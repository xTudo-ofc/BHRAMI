Como montar seu próprio WebSDR

Para criar seu próprio WebSDR você precisará de:

  • QUALQUER DONGLE SDR USB (EX: RTL-SDR)
  • ANTENA COMPATÍVEL (CASEIRA/COMERCIAL) QUE PODE RECEPCIONAR A FAIXA ALVO
  • UM COMPUTADOR LINUX/WINDOWS/RASPBERRY PI/MAC
  • DOMÍNIO OU QUICK TUNNEL CLOUDFLARE

Para criar você tem que baixar o software OpenWebRX original. No Windows você tem que usar o Docker + WSL. No Linux tem como instalar diretamente, incluindo Raspberry Pi.

Após a instalação, execute o programa OpenWebRX com seu SDR conectado. No Windows Docker é necessário o USBIPD.

Após isso, você deve pegar a porta local que o Docker gera (EX: 8080:8080). Você deve pegar o número, por exemplo 8080, e no navegador do seu computador digitar: 

localhost:8080

Esse número é a porta que deve ser usada.

Após isso, você deve usar um domínio que é pago, como example.com, ou um Quick Tunnel da Cloudflare (não é recomendado), em modo Túnel, passando sua porta (EX: 8080) para seu domínio (exemplo.exemplo) ou para um Quick Tunnel.

Após esse passo, teste: abra seu domínio ou Quick Tunnel. Se abrir o OpenWebRX, você conseguiu criar seu próprio WebSDR.

Lembre-se de que todas as informações preenchidas nas settings devem estar corretas e preenchidas.

Obrigado por ver nosso tutorial! Se precisar de mais informações, contate-me ou pesquise.
