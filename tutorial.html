Como montar seu próprio WebSDR

Para criar seu próprio WebSDR você precisará de: - QUALQUER DONGLE SDR USB (EX: RTL SDR) - ANTENA COMPATÍVEL (CASEIRA/COMERCIAL) QUE PODE RECEPCIONAR A FAIXA ALVO - UM COMPUTADOR LINUX/WINDOWS/RASPBERRY PI/MAC - DOMÍNIO/QUICK TUNNEL CLOUDFLARE Para criar você tem que baixar o software OpenWebRX original, no windows você tem que usar o docker+WSL, no linux tem como instalar diretamente incluindo Raspberry PI. Após a instalação execute o programa OpenWebRX com seu SDR conectado (no WIndows Docker é necessario o USBIPD) após isso, você deve pegar a porta local que o docker gera (EX: 8080:8080), você deve pegar o número por exemplo 8080 e no navegador do seu computador digitar: localhost:8080 esse número é a porta que deve ser usada, após isso você deve usar um domínio que é pago como example.com ou um Quick Tunnel da Cloudflare (não é recomendado) em modo Túnel passando sua porta (EX: 8080) para (exemplo.exemplo) ou para um quick tunnel, após esse passo, teste: abra seu domínio ou quick tunnel, se abrir o OpenWebRX você conseguiu criar o próprio websdr, lempre-se de todas as informações preenchidas na settings estarem corretas e preenchidas.
